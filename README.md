# Smart IoT-Based Environmental Monitoring & Security System using ESP32

## 📌 Overview

The **Smart IoT-Based Environmental Monitoring & Security System** is an ESP32-based project designed to monitor environmental conditions and detect security-related events in real time.

The system uses sensors connected to an ESP32 microcontroller to collect environmental data and detect motion. It can provide alerts when a security event is detected, making it useful for smart home, workplace, and other monitoring applications.

## 🚀 Features

* 🌡️ Temperature monitoring
* 🚶 Motion detection
* 🌍 Environmental monitoring
* 🔒 Security event detection
* ⚠️ Alert indication
* 📡 ESP32-based IoT system
* 💻 Simulation using Wokwi

## 🛠️ Technologies & Components

### Hardware

### Software

* Embedded C/C++

* Wokwi Simulator

## ⚙️ Working Principle

1. The ESP32 initializes the connected sensors and components.
2. The temperature sensor continuously monitors the surrounding temperature.
3. The PIR sensor detects motion in the monitored area.
4. The ESP32 processes the sensor readings.
5. When motion or a defined security event is detected, the system activates the appropriate alert.
6. Environmental data and security status can be monitored through the connected system.
